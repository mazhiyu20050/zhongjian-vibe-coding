# 顶部人物卡牌与专属智能体

- 页面顶部中间有15px透明入口，鼠标经过向下展开人物卡牌；也支持点击、触屏与键盘聚焦，Escape收起。展开后保持悬浮，用右上角关闭、空白处点击、Escape或选中人物退出。
- 20位已有审核Skill和原文资料的人物提供本地缓存肖像、姓名和思想标签。古人使用传世画像或雕像；不生成假照片。肖像原图、作者、许可与SHA256保存在 `web/portraits/manifest.json`，面板下方链接打开署名与许可页。
- 卡牌选中开启专属新对话并保留未发送草稿；只传递明确的 `agent_person`，不篡改用户问题、不用人名悄悄拼接原问题。默认多人物模式仍使用原推荐逻辑。
- 专属模式只向路由器提供该人物的Skill观念，并限制选择和原文检索到此人。生成的第一人称解读不是本人历史原话；引用照旧通过来源校验。资料不够时保留边界，不为凑回答借用其他人物。
- 不同模式和人物之间新建独立会话。历史表增量增加 `agent_person` 字段，旧对话不丢失；重启后恢复原人物上下文，不恢复待确认工具授权。
- 右上加号在当前人物模式中新建对话；面板“众见·多人观点”返回默认模式。下载后仍待审核的人物不提前加入卡牌。

## 配套修复
字体统一为本机微软雅黑UI/微软雅黑等清爽无衬线字体，原文不再混用宋体；重点强调保留。回答区顶部保留按钮安全间距。

人物下载不再把所有失败都混成“来源连接异常”：区分GitHub限流、超时、连接中断、证书和访问权限错误。遇限流立即停止重复打接口，按Retry-After/X-RateLimit-Reset等待自动重试，最多两次；等待状态保存在本机，软件关闭后重开仍尊重等待时间。短暂网络故障使用有限退避重试；不跳过证书校验。

重试复用24小时内的已核验人物身份，已有下载校验哈希后复用；搜索优先精确仓库名，减少README泛匹配造成的大量无关请求。未下载成功时不显示成功；下载成功与审核后启用分开。
