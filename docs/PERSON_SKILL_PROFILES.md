# 新人物 Skill 的肖像和简介

下载成功后，后台按已核验的 Wikidata 人物编号准备简介和肖像。简介使用身份描述，若能核对同一编号的中文百科条目，可补充导语。肖像来自该编号的肖像字段，仅缓存许可明确的图片。无照片时在轮盘上显示姓名占位。

下载与接入是两件事。下载文件仍在 `skills-incoming` 中等待审核；已准备的人物资料保存在用户数据目录下的 `person-profiles/<编号>`。等人物目录、已审核的 Skill 清单和可引用的本地语料都接入后，此人方可进入顶部轮盘。重新打开轮盘时会刷新名单。随版本发布的人工编校资料优先于本机暂存资料。

右键人物卡片显示简介和资料出处；左键保持进入人物对话。
