# 导航、历史和后台人物查找

## 界面与本地历史
- 首次打开、新建对话：输入框在视口正中；提交后保持原四宫格/窄屏单列布局。
- 左上圆形三横线打开左侧抽屉，含人物偏好、设置和历史。右上圆形加号新建对话，不删除历史。
- 历史标题采用第一轮 AI 提炼的问题标题，缺失时取问题前24字。历史存在当前用户的本地 SQLite，不做云端同步。回看不请求模型；继续提问、展开详解仍可能产生接口费用。
- 历史保存失败不丢失已完成回答，会显示提示。草稿不自动归档。

## 后台搜索与下载
- `/api/people/jobs` 提交返回202；两个后台工作线程，最多六个活动任务，前端轮询。关闭弹窗不取消任务，刷新后从服务端重新读取。
- 软件完全关闭后任务停止，下次启动标为可重试；不宣称关机后继续下载。
- 简繁归一、中英文 Wikidata 搜索、批量 P31=Q5 真人验证。Wikipedia 搜索作备用实体入口，仍须 Wikidata 真人类型验证。同名候选按姓名/别名匹配、百科覆盖度和检索顺序自动排序，只下载最匹配的一项；这是启发式匹配，不是身份准确率保证。
- GitHub 搜中文名及英文/拼写别名，兼查说明/README，支持根目录和嵌套目录 SKILL.md。
- 系统证书校验、严格域名/端口/重定向白名单、文件大小限制、短暂网络错误重试。来源连接异常与真正未找到分开显示。不运行仓库脚本。
- 下载存在用户数据目录的 `skills-incoming/<QID>/<SHA摘要>/`，保留来源仓库、路径、许可、Git blob和SHA256；重复下载核对哈希后复用。
- 成功状态 `downloaded_pending_review` 不等于启用。外部 Skill 还需内容检查、原著/一手资料和路由校验再参与回答；人物真实存在也不保证有许可明确的公开 Skill。
- 完成任务短期缓存；失败可重试。队列仅存公开人名与来源，不存密钥或个人问题。

## 数据与发布边界
原著和Skill分开：下载的Skill内容不冒充本人原话。新增本地历史的用户需求改变了旧版“对话只在内存”的行为；诊断日志仍不写个人问题/回答。本地修改和重建安装包不等于官网发布，Cloudflare需单独部署。

## 下载交互更新
联网查找改为圆形下载箭头，处理时外圈旋转，视口顶部显示2px细进度条；进度为不定量状态，不伪造下载百分比。任务结束时停止并隐藏进度。旧版等待选择的任务自动迁移继续下载，不再显示选人按钮。
