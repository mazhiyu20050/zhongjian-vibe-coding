# 测试与验收

本次交付在独立目录运行完整 unittest 回归，并保存真实 stdout/stderr 至 reports/unit-tests.txt；环境、结束码和日期在 reports/test-summary.json。离线演示日志见 reports/offline-demo.txt。

测试使用 mock 客户端，不验证当前模型可用性、计费或所有自然语言回答质量。开发期间另曾用真实 API 与网页检查三人物回答、短标签及情绪反思问题占比；为保护私人输入，相关截图和请求记录未上传，也没有把历史检查冒充本次新运行。

建议人工验收：配置个人密钥后，分别测试人际困惑、行动拖延和纯知识查询；确认引用相关、展开内容可读、百分比每人合计100或显示待定；收藏先确认后落盘。不要提交密钥或真实心理问题给 CI。
